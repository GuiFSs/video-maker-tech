# STORYBOARD — `angular-component-intro`

Depende de: `OUTLINE.md` aprovado.

Formato: 1080×1920. Cada cena ~3–8s.

## Cenas

### S01 — Gancho

- **Duração ~:** 5s
- **Texto na tela:** A tela não é um arquivo só
- **Visual:** Título forte + kicker Angular
- **Narração (intenção):** tela montada com peças
- **Transição:** corte

### S02 — Analogia LEGO

- **Duração ~:** 7s
- **Texto na tela:** Peças que se encaixam
- **Visual:** três “blocos” (cards) lado a lado
- **Narração (intenção):** cada peça = pedaço da UI
- **Transição:** corte

### S03 — Conceito

- **Duração ~:** 8s
- **Texto na tela:** Component = visual + lógica
- **Visual:** três pilares: template · estilo · lógica
- **Narração (intenção):** nomear component após a analogia
- **Transição:** corte

### S04 — Exemplo

- **Duração ~:** 8s
- **Texto na tela:** botão · card · header
- **Visual:** três exemplos como components
- **Narração (intenção):** exemplos concretos da interface
- **Transição:** corte

### S05 — Erro comum

- **Duração ~:** 6s
- **Texto na tela:** Component ≠ só HTML
- **Visual:** aviso / warn
- **Narração (intenção):** HTML sozinho não é o pacote completo
- **Transição:** corte

### S06 — Recap + CTA

- **Duração ~:** 6s
- **Texto na tela:** Um bloco reutilizável da tela
- **Visual:** frase de ouro + CTA
- **Narração (intenção):** recap + pergunta
