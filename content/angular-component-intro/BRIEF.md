# BRIEF — `angular-component-intro`

## Tema

O que é um **Component** no Angular (ideia básica, sem API profunda).

## Público

Iniciantes em Angular / front-end que já ouviram “tudo é component” mas não têm intuição clara.

## Uma ideia central

Em uma frase: um component é um pedaço reutilizável da tela — HTML + estilo + lógica juntos — como um bloco de LEGO da interface.

## Gancho (3–5s)

“No Angular, a tela não é um arquivo gigante: ela é montada com peças.”
