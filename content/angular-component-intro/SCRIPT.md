## Narração

Component é só o HTML? Não. Se tudo fica num arquivo só, você acaba copiando o mesmo botão várias vezes. No Angular, você cria um BotaoComponent uma vez: selector app-botao e o template do botão. Na tela, é só chamar: app-botao, app-botao, app-botao. Três botões, o mesmo component. O header também: app-header. Define uma vez, reutiliza onde precisar. Component não é só o HTML. É a peça que você chama de novo. Comenta: o que ainda te confunde?
