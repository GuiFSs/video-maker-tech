## Objetivos de aprendizagem

Ao final, a pessoa consegue:

1. Explicar component com a metáfora do LEGO / peças da tela.
2. Dizer que um component junta visual + comportamento num pacote reutilizável.
3. Reconhecer o erro de achar que “component = só o HTML”.

## Arco pedagógico

| Beat | Função | Conteúdo (1 linha) | Tempo ~ |
| --- | --- | --- | --- |
| 1 | Gancho | Tela não é um arquivo gigante — é montada com peças | 5s |
| 2 | Analogia | Cada peça de LEGO = um pedaço da UI | 7s |
| 3 | Conceito | Component = template + estilo + lógica juntos | 8s |
| 4 | Exemplo | Botão, card, header — cada um pode ser um component | 8s |
| 5 | Erro comum | Component não é “só o HTML” | 6s |
| 6 | Recap + CTA | Uma frase + “o que ainda trava?” | 6s |

## Metáfora visual única

LEGO / peças: a interface é montada encaixando blocos; cada bloco é um component.

## Jargões (só após a analogia)

- component
- template (a parte visual)
- (mencionar de leve) classe/lógica — sem detalhar TypeScript
