# Estilo de referência — TechPulse-like (retenção short-form)

Baseado no screen recording do short de connection pool (Postgres) do TechPulse27.
Objetivo: **curiosidade nos primeiros 2s** + diagrama que **evolui** + voz energética.

## Regra de ouro

**Um canvas. Estados mudam. Não trocar de “slide” a cada frase.**

Cortar só se o assunto mudar de metáfora. No short de um conceito: **1 HTML**, timeline JS controla o que aparece.

## Hook (0–3s)

1. Tensão / pergunta — nunca “hoje vamos falar…”
2. Keyword colorida + underline no título
3. Diagrama já se mexendo no frame 0
4. Caption pill sincronizada com a fala

## Fluxo no mesmo canvas

1. Hook — tensão  
2. Problema visual — caos / bagunça  
3. Conceito — nomear + highlight  
4. Exemplo — mesmo diagrama organizado  
5. Erro comum — contraste rápido  
6. Recap + CTA  

A cada ~5–8s: nova info visual. Congelar >2s sem micro-motion = slide.

## Visual

- Fundo preto/navy; neon cyan / coral / verde
- Ícones simples; tokens nas linhas; pills de caption
- Código só 3–5 linhas, amarrado ao diagrama

## Narração

- Frases curtas; rate +8% a +12%
- **Default do projeto:** `pt-BR-AntonioNeural` (aprovado após comparar com Thalita)

## Anti-padrões

- 6 HTMLs / 6 cortes por conceito
- Cards genéricos sem fluxo
- TTS lento; intro explicativa antes da tensão
