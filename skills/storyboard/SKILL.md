# Storyboard

1. Exija `OUTLINE.md` aprovado.
2. Escreva `STORYBOARD.md` com ids `S01`… alinhados aos beats.
3. Por cena: duração, texto na tela (curto), visual concreto, intenção de narração, transição.
4. Some o tempo; ajuste se sair do alvo do BRIEF.
5. Uma metáfora visual dominante em todas as cenas relevantes.
6. Peça aprovação antes do script.

Não gere HTML aqui — só o storyboard textual.
